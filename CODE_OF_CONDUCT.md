# Code of conduct

This project welcomes everyone who wants to learn, use or improve it.

## Expected behaviour

- Be respectful and assume good intent.
- Give and accept constructive feedback on the work, not on the person.
- Keep discussions on topic and in public issues or pull requests.

## Unacceptable behaviour

- Harassment, insults or discriminatory language.
- Publishing other people's private information.

## Reporting

Report problems privately to the repository owner through their GitHub
profile. Reports are handled confidentially.
